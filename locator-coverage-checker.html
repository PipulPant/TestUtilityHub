Selector Priority Guide
  • data-testid / data-cy / data-test — Best choice. Purpose-built for automation, never changes with UI redesign.
  • id — Unique by definition. Use if it's a stable, human-written ID (not auto-generated).
  • aria-label / role — Semantic and accessibility-driven. Playwright's getByRole() and getByLabel() are strongly preferred.
  • name / placeholder — Reliable for form inputs without test IDs.
  • text content — Breaks if copy changes. Use only when no stable attribute exists.
  • class — Fragile. CSS-in-JS hashes like .sc-abc123 change on every build. Only use stable BEM classes.
